IBCGOS - Homepage

Fichiers :
- index.html : structure de la page
- style.css : mise en forme responsive
- script.js : menu mobile, année automatique et formulaire de démonstration

Utilisation : décompressez le ZIP puis ouvrez index.html dans votre navigateur.
La photo du bandeau et les polices sont chargées depuis Internet. Le formulaire est une démonstration et nécessite un backend pour envoyer réellement les messages.
Les domaines de formation sont des exemples à remplacer par l'offre officielle d'IBCGOS.
